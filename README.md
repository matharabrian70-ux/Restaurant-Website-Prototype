# Savanna Ember Restaurant Website Prototype

A complete Kenyan restaurant showcase concept built for restaurant-manager demonstrations.

## Brand
Savanna Ember — Kenyan Grill · Modern African Kitchen

## Features
- Hero video-ready landing page
- Menu categories: Breakfast, Main Dishes, Desserts, Drinks
- Responsive menu cards and add-to-order interaction
- About, experience, reviews, order CTA and contact sections
- Mobile navigation
- Savanna Ember logo and visual theme assets

The hero includes a poster fallback and is ready for a looping MP4 at `assets/hero-fire.mp4`.
